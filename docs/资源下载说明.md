## 常见问题

### 参考音频 3~10 秒限制

合成报「参考音频在3~10秒范围外」时，换一段时长合规的 wav：

```powershell
ffmpeg -i input.wav -ss 00:00:01 -t 5 -c copy ref.wav
```

### 中文路径

参考音频建议放纯英文路径下（如 `voice/encore/ref.wav`）。项目 `voice/` 内文件名含中文也可，服务端为 Windows 时通常能识别；若报「不存在」请改英文文件名。

### Live2D 模型水印

多数 Live2D 模型自带水印图层。profile 模板里 `watermark.fingerprint: true` 启用自动隐藏；想保留就关掉。

### 启动后桌宠配置

`config.yaml` 的 `character.tts_engine: gptsovits` + 参考音频/文本，其余参数在桌宠设置面板「Live2D」页调整（位置/缩放/水印/挂机随机表情）。

### 一键部署

```powershell
python main.py
# 桌宠启动时自动调 start_tts_api_subprocess() 拉起 GPT-SoVITS 服务（如已开则复用）
```
