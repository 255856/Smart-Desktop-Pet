## 2. GPT-SoVITS 整合包（`GPT-SoVITS-v2pro-20250604-nvidia50/`）

v2ProPlus 版整合包（自带 Python runtime 与全部预训练模型，约 8GB）。

- 下载链接：https://github.com/RVC-Boss/GPT-SoVITS
- 部署：解压到桌宠项目根目录下，保持目录名 `GPT-SoVITS-v2pro-20250604-nvidia50`
- 启动 TTS 服务：双击项目根目录的 **`start_tts_api.bat`**（或手动运行
  `runtime\python.exe api_v2.py -a 127.0.0.1 -p 9880 -c GPT_SoVITS\configs\tts_infer.yaml`）

## 常见问题

- **参考音频 3~10 秒限制**：合成报「参考音频在3~10秒范围外」时，换一段时长合规的 wav。
- **中文路径**：参考音频建议放在纯英文路径下（如本项目 `voice/` 内文件名含中文也可，
  服务端为 Windows 时通常可识别；若报「不存在」请改英文文件名）。
- 桌宠配置：`config.yaml` 的 `character.tts_engine: gptsovits` + 参考音频/文本，
  其余参数在桌宠设置面板「Live2D」页调整。
