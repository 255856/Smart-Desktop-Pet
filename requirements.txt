# ================= [向量检索 · Stage 2.9] =================
# 记忆检索的**语义腿**：Chroma（持久化向量库，派生索引）
#   + sentence-transformers（bge-small-zh-v1.5 向量模型 + bge-reranker-base 交叉编码器重排）。
#
# ⚠️ 版本边界（都是本机实测过的组合）：
#   * sentence-transformers：>=4.41,<6（本机实测 5.7.0 可用；<4.41 没有
#     CrossEncoder 的稳定 API）。
#   * transformers：**必须 < 5**。sentence-transformers 5.7.0 自己的依赖写的是
#     transformers<6，但 5.x 的 transformers 改了 CrossEncoder 依赖的 API，
#     4.41~4.57 这一段才是实测能跑通的（本机 4.57.6）。
#   * chromadb：>=1.0（1.x 的 PersistentClient / get_or_create_collection API
#     与 0.x 不一样；本机实测 1.5.9 可用）。
#
# ⚠️ **USE_TF=0（硬要求）**：
#    本机装了 tensorflow 2.19 + Keras 3，而 transformers 4.x 一见到 Keras 3 就直接
#    raise ValueError("Your currently installed version of Keras is Keras 3, but this
#    is not yet supported in Transformers")。
#    所以凡是 import transformers / sentence_transformers 的地方，**必须先**
#    os.environ.setdefault("USE_TF", "0")。
#    memory_sidecar/store.py 在模块导入时就设好了（桌宠主进程本身从不 import
#    transformers —— 模型只在 sidecar 里加载，所以在这里设是安全的）。
#
# 模型 id 与缓存位置（**模型不随仓库走**）：
#   * 向量模型：BAAI/bge-small-zh-v1.5   （512 维，91.9 MB）
#   * 重排模型（cross-encoder，**两个 id，按设备自动选一个**）：
#       - BAAI/bge-reranker-v2-m3  （约 2.27 GB）→ **有 CUDA 时用它**：
#           GPU 上 16 对重排 41ms、语义用例分离度 2.7x
#       - BAAI/bge-reranker-base   （约 1.08 GB）→ **没有 CUDA 时用它**：
#           CPU 上 291ms；同一件事 v2-m3 在 CPU 要 1016ms（反而更慢），而且它
#           GPU 209ms / 分离度只有 1.28x（几乎分不开）
#     选择规则写在 memory_sidecar/store.py 的 resolve_rerank_model()：
#       torch.cuda.is_available() → v2-m3，否则 → base；
#       DESKTOP_PET_MEMORY_RERANK 一旦设了就听它的（自动选择只在没设时生效）。
#     启动时会打一行日志说明「选了哪个、为什么」。
#   * 缓存在 HuggingFace 默认缓存目录（Windows 上就是用户目录下的）：
#       %USERPROFILE%/.cache/huggingface/hub
#     里面的目录名是 models--BAAI--bge-small-zh-v1.5 /
#     models--BAAI--bge-reranker-v2-m3 / models--BAAI--bge-reranker-base。
#   * **运行时默认不自己下载**：聊天路径上悄悄下模型会跟聊天抢
#     磁盘 / CPU / 带宽，主人的体感是「桌宠变笨了」而不是「模型在下载」。
#     要开语义检索就**显式**跑一次（幂等，带进度和校验）：
#         python scripts/prefetch_models.py          # 下载 + 校验
#         python scripts/prefetch_models.py --check  # 只看模型在不在（不下载）
#     下完在面板里点「重建向量索引」即可（详见 README「可选：语义记忆检索」）。
#   * 模型没下载 / 没网 → 索引不可用 → 记忆检索自动退回 substring + TF-IDF
#     （桌宠照常工作，测试照常全绿），而且**主人看得见**：桌宠冒泡说一声 +
#     面板「健康与维护」显示「向量模型：没下载」+ 该跑哪条命令。
#   * 确实想让运行时自己下（后台线程，不阻塞聊天，但会抢资源）：
#         set DESKTOP_PET_VECTOR_ALLOW_DOWNLOAD=1
#
# ⚠️ 体积提醒：这两个包会带进 torch（CUDA 版约 2.5 GB）。
#    CI（.github/workflows/test.yml）会跑 pip install -r requirements.txt，
#    装它们会让 CI 多下 ~2.5 GB；如果 CI 时间/空间吃紧，
#    可以把下面三行注释掉（记忆检索自动退回 TF-IDF，测试仍然全绿）。
sentence-transformers>=4.41,<6
transformers>=4.41,<5
chromadb>=1.0
