一、Live2D 渲染与动作

能力网页 Demo说明 / 桌面版差异
模型加载（内置 / URL / 拖拽）已对齐内置零配置自动加载；本轮补齐了 URL 加载按钮 与 拖入 .model3.json 链接（此前只有方法、没有入口，拖拽提示是死元素）。
动作播放已对齐7 组动作可播放，实测 playMotion 正常。

口型同步已对齐SpeechSynthesis 的 start/end 边界事件驱动 ParamMouthOpenY，与桌面思路一致。

隐藏 WaterMark / mask 纹理扩展已对齐已实现。

二、语音（TTS / ASR）

能力网页 Demo说明 / 桌面版差异
语音朗读 + 口型简化用浏览器 SpeechSynthesis 发声；默认锁定 Xiaoxiao。
edge / gptsovits / minimax 三引擎模拟下拉可切换，但三者底层都走浏览器语音，仅按引擎挑选不同音色；并非真实 edge-tts / GPT-SoVITS / MiniMax API。
多角色音色（characters）缺失桌面版有独立角色音色库。
语音识别（按住说话）简化用浏览器 Web Speech API；桌面版用 faster-whisper（本地、可离线、识别更准）。

三、对话 / 大脑 / Agent

能力网页 Demo说明 / 桌面版差异
流式对话 + 气泡已对齐OpenAI 兼容 chatStream 增量渲染；无 key 时 mock 兜底。
主动搭话 + 时间上下文已对齐ProactiveBrain 定时（25–45 分钟）+ 时段文案。
意图识别简化用正则关键词（提醒/搜索/记住/动作）；桌面版用 LLM 意图识别，更鲁棒。
自主工具调用循环（ReAct）缺失这是最大差距：桌面版 AgentLoop 可像 Claude Code 一样自主多轮调用多个工具、规划/反思/重规划后再总结；Demo 仅正则命中后单次调用，无“先分析再作答”。
结果总结 / 核实缺失桌面版 final 阶段会汇总工具结果。
多 Agent（Life/Research/Code + Orchestrator）缺失狼人杀等场景依赖多 Agent。
MCP 工具协议缺失桌面版支持 MCP stdio / filesystem server。

四、工具集（Function Calling）

能力网页 Demo说明 / 桌面版差异
网页搜索简化仅 Tavily（无 key 用 mock）；桌面版 Tavily 主用、DuckDuckGo 降级。
记忆 / 提醒 / 通知简化remember / search / forget、提醒增删、浏览器 Notification 可用；缺 delete 提醒的 UI 入口。
时间 / 日期 / 计算 / 单位换算缺失浏览器本可实现（Date / 计算），建议补。
打开网站缺失window.open 即可实现，建议补。
宠物状态 / 喂食 / 表情 / 说话缺失网页无养成状态系统。
打开本地应用 / 快捷方式 / 系统信息缺失浏览器沙箱无法启动本地程序、任务管理器、终端、记事本等（平台限制）。
截图 / 读本地文件 / 剪贴板写入缺失受浏览器安全限制（截图/文件基本不可行，剪贴板仅可有限读写）。
桌面版共注册约 32 个工具；Demo 实际可用的工具类能力约 4 类（搜索、记忆、提醒、通知）。

七、本轮测试中发现并已修复

  • “加载模型 URL”功能名存实亡：loadModel() 与 URL 校验早已写好，但页面没有任何入口；已在功能面板「模型与密钥」新增 加载模型 URL 按钮（实测 http/https 接受、file:// 与本地盘符路径拒绝、少斜杠自动补全）。
  • 拖拽提示是死元素：#drop-hint 存在但没有任何 drag/drop 事件；已补全拖拽（仅支持拖入 http(s) 的 .model3.json 链接，拖入本地文件时给出友好提示，符合浏览器沙箱限制）。
  • 提醒文案吃掉“我”字：说“3分钟后提醒我喝水”，内容被记成“我喝水”；已修正正则，实测内容正确为“喝水”。
  • 启动状态文案误导：“请填写 Model URL”在没有输入框时显示；已改为“正在加载内置模型…”。

八、补齐建议（按可行性）

网页端可补齐（推荐）

  • 把 LLM Function Calling 接上：让模型自主选择 时间 / 搜索 / 记忆 / 提醒 / 打开网站 / 计算 等工具并多轮调用，最后只在气泡输出总结（这是最能拉齐桌面体验的一项）。
  • 新增工具：get_current_time / date_info / calculate、open_website(window.open)、clipboard_copy。
  • 记忆用 localStorage 做轻量的重要性与最近访问排序；聊天历史持久化。
  • 给“提醒列表/删除”补 UI 入口（API 已具备）。

仅桌面可行（平台限制，网页不必强求）

  • 启动本地应用、任务管理器/终端/控制面板、读取本地文件、系统截图。
  • faster-whisper 本地识别、GPT-SoVITS 本地音色克隆。
  • Sprite 帧动画、托盘、窗口拖拽/触摸热区、系统级通知。
  • 养成数值、食物、金币、五子棋/狼人杀等重玩法（可移植但工作量大，且偏离“网页能力 Demo”定位）。
结论：网页 Demo 在 Live2D 渲染、聊天、口型、主动搭话、基础记忆/提醒/搜索 这条“展示主线”上与桌面版基本对齐；最大差距集中在 Agent 自主工具循环、工具数量（32 vs 4） 与 养成/游戏/系统级能力，其中后者多为浏览器平台天然限制，前者是网页端最值得优先补齐的部分。
